## 🐾 Registro Civil de Mascotas

Aplicación web para inscribir mascotas junto al RUT de su dueño/a, consultar
el registro completo o filtrar por nombre de la mascota / RUT del dueño, y
eliminar inscripciones — todo desde una interfaz simple conectada a una API
propia construida en Node.js.

> ⚠️ **Nota:** el proyecto está desplegado en el free tier de Render, el cual
> "duerme" el servidor tras un período de inactividad. Si al insertar o
> consultar datos no responde de inmediato, espera unos segundos y vuelve a
> intentarlo — el servidor solo necesita despertar.

🔗 **Demo en vivo:** [https://ministerio-de-las-mascotas.onrender.com/](https://ministerio-de-las-mascotas.onrender.com/)
